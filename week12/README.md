# week12 데이터 분석

## 데이터
- 출처: AI 협업 프로그래밍 12주차 실습 배포 자료로 제공된 `scores_2026.csv` (외부 공개 데이터가 아닌 수업용 실습 데이터)
- 파일 형식/인코딩: CSV / UTF-8
- 원본 크기: 114행 × 5열 (헤더 제외 데이터 행 기준)
- 열 설명:
  - `학번`: 학생 번호, 문자형으로 읽음
  - `이름`: 학생 이름
  - `반`: 1반 또는 2반
  - `과목`: 프로그래밍, 영어, 수학
  - `점수`: 0~100 사이 정수 점수
- 빈 칸 처리: `점수`가 비어 있는 행 6개는 삭제함. 점수가 없으면 평균·합계 등 수치 통계에 사용할 수 없어 임의의 값으로 채우지 않음.
- 중복 처리: 모든 열이 완전히 같은 행은 한 건만 유지함. 동일한 관측값이 중복 집계되는 것을 막기 위함.
- 문자열 처리: `반`, `과목`의 앞뒤 공백을 제거함. 공백 때문에 같은 반/과목이 다른 범주로 나뉘는 것을 막기 위함.
- 이상 점수 처리: 0~100 범위를 벗어난 4행(999점 3개, -5점 1개)은 삭제함. 과제에서 정한 점수 유효 범위를 위반하기 때문.
- 정제 결과: 100행, 반 2종류, 과목 3종류.
- 손계산 검증용 `mini.csv`: 10행 원본, 정제 후 7행.
